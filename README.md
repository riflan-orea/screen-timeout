## macOS Notification Troubleshooting

If notifications are not displaying on macOS but you hear the sound, try these steps:

### 1. Check System Settings
- Go to **System Settings** > **Notifications**
- Find your browser (Safari, Chrome, Firefox) in the list
- Ensure **Allow Notifications** is enabled
- Set notification style to **Banners** or **Alerts**
- Make sure **Play sound for notifications** is enabled

### 2. Disable Focus Modes
- Click the **Control Center** icon in the menu bar
- Turn off **Do Not Disturb** or any active **Focus** modes
- Or go to **System Settings** > **Focus** and disable active modes

### 3. Browser-Specific Settings

#### Safari:
- Go to **Safari** > **Settings** > **Websites** > **Notifications**
- Ensure the app domain is set to **Allow**
- Try refreshing the page and re-enabling notifications

#### Chrome:
- Go to **Chrome** > **Settings** > **Privacy and security** > **Site Settings** > **Notifications**
- Ensure the app domain is set to **Allow**

### 4. Debug Tools
The app includes built-in debugging tools:
- Enable notifications in the app
- Click **Debug Notification Environment** button
- Check browser console for detailed information
- Use **Send Test Notification** to verify functionality

### 5. Common Issues
- **Service Worker conflicts**: Clear browser cache and reload
- **Permission denied**: Remove site from notification settings and re-enable
- **Focus modes active**: Disable all Focus modes in System Settings
- **Display mirroring**: Enable "Allow notifications when mirroring or sharing the display" in System Settings > Notifications

If issues persist, try:
1. Restart your browser
2. Clear browser cache and cookies
3. Reset NVRAM (hold Option+Command+P+R during startup)
4. Check for macOS updates
